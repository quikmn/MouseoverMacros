# MouseoverMacros

WoW Forever (interface 16001). `/mom` opens a window with your class's mouseover macros: switch each on or off, create or update one, pick it up to put it on a bar, or create / update all the switched-on ones at once (`/mom install`). Macros that already exist are edited in place, so your bars keep working. New macros go to your character macros (account macros when those are full), or to account macros if you choose. `/mom help` lists the chat commands.

- Friendly spells: mouseover, then friendly target. Never yourself.
- Hostile spells: mouseover, then target.
- Dispel Magic: mouseover, then target, friend or enemy (cleanse or purge).
- Turns off the game's Auto Self Cast setting on every login.

Classes covered so far: Priest.
