# MouseoverMacros

WoW Forever (interface 16001). `/mom` opens a window with your class's mouseover macros: switch each on or off, create or update one, pick it up to put it on a bar, or create / update all the switched-on ones at once (`/mom install`). Its macros are named `_mom` plus four random digits (for example `_mom4821`) and /mom remembers which ones it made: it only ever updates those, in place, so your bars keep working, and never touches a macro of yours, even one with the same name. Old plain-named /mom macros are renamed to `_mom` names at login if their text is unchanged. Bar addons show the macro name under the button; Bartender4's "Hide Macro Text" hides it. New macros go to your character macros (account macros when those are full), or to account macros if you choose. `/mom help` lists the chat commands.

- Friendly spells: mouseover, then friendly target. Never yourself.
- Hostile spells: mouseover, then target.
- Dispel Magic: mouseover, then target, friend or enemy (cleanse or purge).
- Turns off the game's Auto Self Cast setting on every login.

Classes covered so far: Priest.
